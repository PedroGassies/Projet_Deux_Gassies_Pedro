# booki-starter-pack
Ce projet, réalisé dans le cadre de la formation Développeur Web chez OpenClassrooms, consiste en la création d'une interface web pour une agence de voyage appelée Booki. Il s'agit de découper et d'intégrer une maquette Figma en utilisant HTML et CSS, tout en assurant la responsivité du site pour une compatibilité optimale sur divers appareils et résolutions d'écran.
